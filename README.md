## 项目简介

一款集骑行数据、GNSS 导航、离线地图、语音交互和无线通信于一体的智能骑行终端。

## 技术栈

ESP32-P4 · ESP32-C5 · ESP-IDF · FreeRTOS · LVGL · BLE · Wi-Fi

## 核心功能

- 骑行数据
- GNSS 导航 / 离线地图
- BLE / Wi-Fi 通信
- 语音交互
- 微信小程序
