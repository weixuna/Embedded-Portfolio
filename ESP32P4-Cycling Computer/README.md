## 作品介绍
基于 ESP32-P4 + ESP32-C6 的智能骑行导航终端：P4 负责 AMOLED 显示、触摸、地图、路线、定位和 UI，C6 通过 ESP-Hosted SDIO 提供 BLE/Wi-Fi；手机通过 BLE 下发路线、天气并同步骑行记录，设备本地完成离线地图、导航、语音播报和小智语音。
